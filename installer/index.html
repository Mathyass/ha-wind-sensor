Know your wind.

Connect your sensor, install the firmware and bring wind speed in km/h into Home Assistant.

1. Wire your sensor

Seeed Studio XIAO ESP32-S3 + LaskaKit WH-SP-WS01. Disconnect power before wiring.

Reed contact → D3 / GPIO4
Other wire → GND

The contact has no polarity. Use D3, not D4. Attach the external Wi-Fi antenna and a USB-C data cable.

2. Install and connect to Wi-Fi

Use Chrome or Edge on a computer. Close other serial monitors. Select the USB device, install the firmware in the wizard, then connect to your 2.4 GHz Wi-Fi network.

Installation replaces the existing firmware. For a clean first test, choose to erase the device; this also removes saved Wi-Fi credentials.

Checking the installation package…

This browser does not support Web Serial. Open this page in desktop Chrome or Edge. The installer requires HTTPS or localhost.

If the device does not respond after flashing, unplug and reconnect USB, then connect again. You can configure Wi-Fi without flashing again.

3. Add to Home Assistant

In Settings → Devices & services, add the discovered ESPHome device. Your main entity is Wind Speed, measured in km/h.

If discovery does not find it, add the ESPHome integration manually using the sensor’s IP address and port 6053. Your computer, sensor and Home Assistant must be able to reach each other on the network.

Add an ESPHome device

4. Updates and full control

Stable releases appear in Home Assistant as Firmware Update. Review the release notes, then install the update from the device page.

For custom changes, open ESPHome Device Builder and choose Take control on the discovered HA Wind Sensor. The Builder creates your own configuration and future builds can be installed wirelessly.

These public update and adoption links become active when this beta repository and installer are published.

Need a hand connecting?

  • No USB device listed? Try another data cable. Hold BOOT, briefly press RESET, then release BOOT. You may need to press RESET after flashing.
  • Wi-Fi will not connect? Check the antenna and your 2.4 GHz network. After about a minute, an open setup network appears, named after HA Wind Sensor with a unique suffix. Join it and open 192.168.4.1.
  • Check the reading: spin the anemometer. After it stops, the speed should return to zero in about 5 seconds.

This test firmware has an open fallback access point, an unencrypted API and OTA without a password. Use a trusted network. See the README for per-device security settings.

HA Wind Sensor · test firmware · Wi-Fi credentials go directly to your device through Improv or its captive portal. Firmware updates use the public HTTPS manifest. The web library loads from unpkg.com; internet access is required.
